# ReadStep
Learn to Read. Read with Confidence.

A professional Android reading-learning app for Bengali and English learners.

## Build
Open/import this Gradle project in a current Android development environment and run:
`./gradlew assembleDebug`

Release APK output:
`app/build/outputs/apk/release/`

The GitHub Actions workflow builds the debug APK automatically and uploads it as an artifact.

## Version 1 starter
This project contains the foundation for onboarding, language selection, reading-level dashboard, lessons, Reading Assistant, difficult words, progress, dark mode and accessible UI. Content and advanced OCR/database features can be expanded in subsequent builds.
